# Agent Instructions

- Always reply to the user in English.
- Build the application UI as bilingual Arabic/English.
- Arabic UI must use RTL layout.
- English UI must use LTR layout.
- Use English for code, file names, API routes, database tables, variables, and comments.
- Keep Arabic only inside translation strings and user-facing Arabic UI copy.
- Preferred async action-button feedback: show a loading label while the request runs, show a success label briefly after completion, then restore the original label; disable the button during the transition and prevent duplicate submissions.
